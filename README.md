# 👕 FitVision AI

> An AI-powered Virtual Try-On and Body Measurement web application built using MediaPipe Pose and Three.js.

## 📖 About the Project

FitVision AI is a personal project that I built to learn more about **Computer Vision**, **Artificial Intelligence**, and **3D web development**.

The application uses **MediaPipe Pose** to detect body landmarks through a webcam and estimate body measurements like shoulder width. Based on these measurements, it recommends a clothing size and provides a simple virtual try-on experience using Three.js.

This project helped me understand how AI can be used in real-world applications like online fashion shopping and virtual fitting rooms.

---

## ✨ Features

- 📷 Live webcam detection
- 🦴 Real-time body pose detection
- 📏 Shoulder width estimation
- 📐 Estimated body measurements
- 👕 Clothing size recommendation (S–5XL)
- 🎽 Simple 3D virtual try-on
- 🎨 Multiple shirt colors and styles
- 📊 Live dashboard with measurements
- 🌙 Modern responsive UI
- ⚡ Works completely in the browser

## 🚀 How to Run

Clone the repository

```bash

```

Go to the project folder

```bash

```

Open the project using **VS Code Live Server** or any local web server.
